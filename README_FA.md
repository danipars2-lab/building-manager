# مدیریت هوشمند ساختمان — نسخه پایه

## امکانات موجود
- ثبت مشخصات یک ساختمان
- ثبت/ویرایش اطلاعات واحدها: شماره، مالک، ساکن، متراژ و تعداد نفرات
- تعریف شارژ با مبلغ ثابت + مبلغ به‌ازای هر نفر و ثبت برای دوره مشخص
- ثبت وصولی واحدها و ثبت هزینه‌های ساختمان
- داشبورد وصولی، هزینه، موجودی صندوق و بدهی شارژهای ثبت‌شده
- گزارش خلاصه و ریز تراکنش‌ها و مانده هر واحد
- خروجی Excel و PDF (PDF این نسخه پایه برای فارسی نیازمند افزودن فونت فارسی و شکل‌دهی متن است)
- پشتیبان‌گیری از پایگاه داده
- ذخیره‌سازی محلی SQLite و عملکرد آفلاین

## اجرای دسکتاپ برای توسعه
```bash
python -m pip install kivy openpyxl reportlab
python main.py
```

## ساخت APK در Linux
نیازمند Linux (ترجیحاً Ubuntu)، Java، Android SDK/NDK و Buildozer:
```bash
python -m pip install buildozer
buildozer android debug
```
فایل APK پس از ساخت در پوشه `bin/` قرار می‌گیرد.

## نکته مهم درباره نسخه فعلی
این تحویل یک اسکلت اجرایی اولیه با عملیات اصلی و ذخیره‌سازی واقعی است، نه نسخه حسابداری نهاییِ ممیزی‌شده. در این نسخه، امکان پیوست تصویر فاکتور، ویرایش/حذف تراکنش از رابط، تفکیک دوره پرداخت در فرم وصولی، انتخاب تاریخ شمسی، مدیریت عناوین پایه از داخل UI، رمز مدیر، و PDF فارسیِ شکل‌دهی‌شده هنوز تکمیل نشده‌اند. پیش از استفاده مالی واقعی، محاسبات و سناریوهای حسابداری باید تست شوند.

## روش ساده‌تر ساخت APK بدون نصب WSL روی ویندوز (GitHub Actions)

۱. یک حساب GitHub بسازید و یک مخزن (Repository) خالی با نام `building-manager` ایجاد کنید.
۲. فایل ZIP را از حالت فشرده خارج کنید و محتویات پوشه `building_manager` را در مخزن بارگذاری کنید؛ پوشه مخفی `.github` را هم حتماً بارگذاری کنید.
۳. در GitHub وارد زبانه Actions شوید. اگر پیام فعال‌سازی Actions دیدید، آن را فعال کنید.
۴. گردش‌کار `Build Android APK` را اجرا کنید یا یک Commit به شاخه main بفرستید.
۵. پس از پایان موفق اجرا، در صفحه اجرای workflow قسمت Artifacts فایل `building-manager-debug-apk` را دریافت کنید.
۶. فایل APK داخل ZIP دانلودشده را به گوشی منتقل و نصب کنید.

این فرایند ساخت در سرورهای GitHub انجام می‌شود و نیازی به نصب Ubuntu یا Android SDK روی کامپیوتر شخصی ندارد. برای استفاده از GitHub Actions ممکن است محدودیت‌های حساب و سهمیه رایگان GitHub اعمال شود.
